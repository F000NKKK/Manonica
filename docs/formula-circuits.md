# Формульные магические конструкции в Manonica Lab

Первая версия связывает **геометрию** и **материальное поглощение** через одну
математическую траекторию. Не существует специальных операций FIRE/BREAK:
формула описывает координаты физических ловушек, а захват рассчитывается
тем же материалом, что и в `manonica-physics`.

## Наглядное сравнение трёх формул

При запуске без аргументов открывается `formula_comparison.toml`.
На экране одновременно представлены **три разные конструкции**:

- слева — зелёная окружность в плоскости XY;
- в центре — оранжевая пятиконечная звезда, полученная радиальной гармоникой `cos(5*t)`;
- справа — синяя пространственная кривая, зависящая от всех трёх координат.

Для каждого контура отдельная исходная концентрация, материальная
ловушка, реальный захват и энергетический баланс.
В F3 дополнительно отображаются `FORMULA 1/2/3 BOUND` — отдельные
запасы связанных манонов по контурам.

```bash
cargo run --release --manifest-path apps/manonica-lab/Cargo.toml
```

В редакторе (клавиша **E**) рисунок формулы появляется немедленно,
**до Enter**, в проекциях X/Y и X/Z. Клавиши **1**, **2**, **3**
загружают окружность, звезду и пространственный узел. **←/→** выбирают,
какой из существующих контуров редактировать, **Tab** переключает координату,
**Enter** применяет изменение к геометрии и физике. Параметры материала
у выбранной конструкции не сбрасываются.

## Переключение сравнения внутри запущенного Lab

Если в заголовке окна написано **«Формульная ловушка — захват манонов»**,
запущен эксперимент с одной формулой (`CIRCUIT 1/1`). Это нормально:
файл `formula_capture.toml` предназначен только для исследования
поглощения одним кольцом.

Нажмите **Esc**, чтобы выйти из редактора, затем **C**, чтобы без
перезапуска перейти на эксперимент с тремя формулами. Заголовок окна
сменится на **«Сравнение трёх формул»**, а контуры будут перестроены.
Поскольку это новый эксперимент, физические величины сбрасываются
к начальным условиям.

При открытом редакторе (E) F3 закрепляется в нижнем левом углу,
чтобы не закрывать ввод формул.

## Редактор внутри окна

1. Запустите Manonica Lab и нажмите **E**, чтобы открыть редактор.
2. Используйте **Tab** для перехода между тремя строками `x(t)`, `y(t)`, `z(t)`.
3. Введите выражения клавиатурой; **Backspace** удаляет символ.
4. Нажмите **Enter**: формула проверяется, а затем меняются геометрия
   контура и физические ловушки без перезапуска окна. Численная
   симуляция начинается с начальных условий.
5. **Esc** отменяет изменения. Камера после закрытия возвращается в
   режим управления мышью.

Редактор изменяет **выбранную стрелками** формульную конструкцию, сохраняя остальные.
Если новое расположение ловушек пересекает уже существующие материальные
ячейки или выходит за границы сетки, на экране появится ошибка и прежняя
симуляция сохранится. Для нескольких сложных структур удобно
использовать TOML, где можно задать произвольное число `[[formulas]]`.

Пример пространственного контура:

```text
x(t) = 2*cos(t)
y(t) = 0.7*sin(3*t)
z(t) = 2*sin(t)
```

**Важно:** параметры `capacity`, `capture_rate`, `binding_energy`,
`max_flux` пока задаются в конфигурации или используются настройки
профиля редактора. Это **не** универсальная физическая магическая формула:
потенциалы, связанные объёмные элементы, резонанс и материальные
напряжения будут подключаться отдельными расчётными законами.

## Запуск

```bash
cargo run --release --manifest-path apps/manonica-lab/Cargo.toml -- \
  apps/manonica-lab/experiments/formula_capture.toml
```

Вариант с явным описанием всех материальных параметров в TOML. Например:

```toml
[[formulas]]
name = "Поглощающий круг"
x = "2*cos(t)"
y = "-0.8"
z = "2*sin(t)"
segments = 96
thickness = 0.035
color = [0.2, 0.9, 0.6]

[formulas.trap]
capacity = 2500.0
capture_rate = 0.18
release_rate = 0.002
binding_energy = 0.08
heat_capacity = 100.0
reference_temperature = 300.0
activation_temperature = 300.0
max_flux = 75.0
```

`t` изменяется от 0 до 2π. Поддерживаются арифметические выражения и
функции библиотеки `meval` (например, `sin`, `cos`, `sqrt`, `exp`).
Три функции создают замкнутую параметрическую кривую, а не просто
декоративный объект. Возможны наклонные и пространственные контуры;
незамкнутые траектории пока не поддерживаются.

Ловушки устанавливаются в уникальные ячейки, пересекаемые узлами
дискретизации кривой. Полная ёмкость и предельный поток делятся между
ними: увеличение `segments` **не** увеличивает запас энергии.
При пересечении другой ловушки или выходе за границы сетки
эксперимент отклоняется.

F3 показывает `FREE`, `BOUND`, `TOTAL` и `ENERGY`.
Свободные маноны переходят в связанные; поток не создаёт новых манонов.
Тепло и энергия связывания учтены отдельно, разряд ограничен энергией.

## Текущие ограничения

- Численная привязка ловушки выполняется в ячейках, в которых находятся
  **образцы траектории**, не на всей непрерывной линии.
- Геометрия влияет на расположение мест захвата, но ещё не решает
  уравнение магического потенциала и не формирует резонанс.
- В редакторе окна доступны координатные выражения. Полный набор\n  физических параметров пока редактируется через TOML.
- Облако всё ещё рисуется прозрачными плоскостями. Настройки
  `TEXTURE_SIZE = 4` и `MAX_PLANES = 64` сохранены, но полноценный
  Ray Marching пока не реализован.
- Энергетический баланс модели фиксирует тепло и энергию связи относительно
  свободного состояния, а не все формы энергии из итоговой спецификации v0.1.
