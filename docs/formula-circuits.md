# Формульные магические конструкции в Manonica Lab

Первая версия связывает **геометрию** и **материальное поглощение** через одну
математическую траекторию. Не существует специальных операций FIRE/BREAK:
формула описывает координаты физических ловушек, а захват рассчитывается
тем же материалом, что и в `manonica-physics`.

## Запуск

```bash
cargo run --release --manifest-path apps/manonica-lab/Cargo.toml -- \
  apps/manonica-lab/experiments/formula_capture.toml
```

Формулы вводятся в TOML-файл эксперимента (пока нет редактора прямо в окне).
При изменении формулы перезапустите Lab. Например:

```toml
[[formulas]]
name = "Поглощающий круг"
x = "2*cos(t)"
y = "-0.8"
z = "2*sin(t)"
segments = 96
thickness = 0.035
color = [0.2, 0.9, 0.6]

[formulas.trap]
capacity = 2500.0
capture_rate = 0.18
release_rate = 0.002
binding_energy = 0.08
heat_capacity = 100.0
reference_temperature = 300.0
activation_temperature = 300.0
max_flux = 75.0
```

`t` изменяется от 0 до 2π. Поддерживаются арифметические выражения и
функции библиотеки `meval` (например, `sin`, `cos`, `sqrt`, `exp`).
Три функции создают замкнутую параметрическую кривую, а не просто
декоративный объект. Возможны наклонные и пространственные контуры;
незамкнутые траектории пока не поддерживаются.

Ловушки устанавливаются в уникальные ячейки, пересекаемые узлами
дискретизации кривой. Полная ёмкость и предельный поток делятся между
ними: увеличение `segments` **не** увеличивает запас энергии.
При пересечении другой ловушки или выходе за границы сетки
эксперимент отклоняется.

F3 показывает `FREE`, `BOUND`, `TOTAL` и `ENERGY`.
Свободные маноны переходят в связанные; поток не создаёт новых манонов.
Тепло и энергия связывания учтены отдельно, разряд ограничен энергией.

## Текущие ограничения

- Численная привязка ловушки выполняется в ячейках, в которых находятся
  **образцы траектории**, не на всей непрерывной линии.
- Геометрия влияет на расположение мест захвата, но ещё не решает
  уравнение магического потенциала и не формирует резонанс.
- Нет редактирования формулы внутри окна; ввод производится в файле.
- Облако всё ещё рисуется прозрачными плоскостями. Настройки
  `TEXTURE_SIZE = 4` и `MAX_PLANES = 64` сохранены, но полноценный
  Ray Marching пока не реализован.
- Энергетический баланс модели фиксирует тепло и энергию связи относительно
  свободного состояния, а не все формы энергии из итоговой спецификации v0.1.
