# Manonica

**Manonica** — математическая система магической инженерии для Minecraft.

Мана моделируется как фундаментальные частицы (*маноны*) в свободном, связанном и преобразованном состояниях. Магические конструкции управляют полями, потоками и преобразованиями материи. Круги — частный случай произвольных трёхмерных конструкций, геометрия которых влияет на их работу.

## Архитектурный принцип

**Ядро не зависит от Minecraft, версии игры или загрузчика модов.** Первая целевая интеграция — Minecraft Java Edition **26.3 / Fabric**, но это лишь первая запись в матрице совместимости, а не ограничение проекта.

- `crates/manonica-physics` — вычислительные модели маны (Rust).
- `crates/manonica-control` — алгоритмы регулирования и магического ТАУ (Rust).
- `apps/manonica-simulator` — автономная лаборатория и эксперименты (Rust).
- `adapters/minecraft/fabric/mc26_3` — первый адаптер Minecraft (Java 25 / Fabric).
- `docs/` — архитектура, ограничения модели, дорожная карта.

## Начало работы

Для физического ядра нужен стабильный Rust:

```bash
cargo test --workspace
cargo run -p manonica-simulator
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
```

Для первого Minecraft-адаптера нужны JDK 25 и Gradle 9.6:

```bash
cd adapters/minecraft/fabric/mc26_3
gradle build
gradle runClient
```

Gradle Wrapper пока не включён; можно создать его в каталоге адаптера командой `gradle wrapper --gradle-version 9.6.0` после установки Gradle. Сборка игрового адаптера пока не подключена к нативной физике.

## Принципы

1. Законы магии едины для всех платформ.
2. Константы калибруются экспериментально в симуляторе, а не объявляются неизменными заранее.
3. Конструкции влияют на физику, а не только на визуал.
4. Изменения Minecraft-мира выполняет адаптер по результатам симуляции.
5. Новые загрузчики и версии игры добавляются как адаптеры; ядро остаётся прежним.
