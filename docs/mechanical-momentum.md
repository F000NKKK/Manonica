# Механика: динамическое скалярное поле и импульс

Статус: математический контракт и экспериментальный одномерный стенд.
Сетка Lab остаётся квазистатической; механическая сила на блоки ещё
не реализована. Коэффициенты ниже — параметры исследуемой модели.

## Почему одного дрейфа недостаточно

Закон `J=-M*n*grad(phi)` описывает перенос концентрации в среде.
Он не задаёт массу, скорость ускоряемого тела или импульс поля.
Поле Lab создаётся заданными источниками и условиями на границе;
их опоры могут обмениваться импульсом с внешним миром. Приписывать
этой открытой системе сохранение импульса без учёта опор нельзя.

Для закрытого стенда примем динамическое поле с лагранжианом

```text
L = sum_a m_a*|v_a|²/2
    + integral( a*phi_t²/2 - epsilon*|grad(phi)|²/2 - s*phi²/2 ) dV
    - sum_a q_a*phi(X_a)
```

`phi` измеряется в Дж/манон, `q` — в манонах, `m` — в кг,
`s` и `epsilon` имеют те же размерности в плотности энергии, что и
квазистатическая модель. `a` имеет размерность
`Дж*с²/(м³*(Дж/манон)²)` и задаёт инерционность поля.
Заряды здесь фиксированы; обмен свободными/связанными манонами
в эту механическую модель пока не включён.

Уравнения вариационной модели:

```text
a*phi_tt - epsilon*laplacian(phi) + s*phi = -rho_q
rho_q(x) = sum_a q_a*delta(x-X_a)
m_a*X_a_tt = -q_a*grad(phi)(X_a)
```

Для распределённого объекта дельта заменяется нормированным ядром,
а сила вычисляется производной той же энергии взаимодействия по X.
Знак правой части важен: в статическом пределе существующий `source`
соответствует `-rho_q`. Существующие источники Lab автоматически
не становятся механическими зарядами.

В периодической замкнутой области:

```text
P_body = sum_a m_a*v_a
P_field = -integral( a*phi_t*grad(phi) ) dV
P_total = P_body + P_field
H = sum_a m_a*|v_a|²/2
    + integral( a*phi_t²/2 + epsilon*|grad(phi)|²/2 + s*phi²/2 ) dV
    + sum_a q_a*phi(X_a)
```

Из уравнений `dP_body/dt=-integral(rho_q*grad(phi))dV`,
`dP_field/dt=+integral(rho_q*grad(phi))dV`; поэтому `dP_total/dt=0`.
Для непериодической области добавляются потоки напряжений через границу,
реакции опор, внешний импульс и работа. Они должны попасть в отдельный
реестр до включения неподвижных источников или внешней нагрузки.

## Независимый двухмодовый стенд

`apps/manonica-simulator/src/bin/field_momentum.rs` ограничивает поле
одной парой Фурье-мод на периоде `L=2*pi/k`:

```text
phi(x) = A*cos(k*x) + B*sin(k*x)
H = p²/(2m) + (PA²+PB²)/(2*mu)
    + mu*omega²*(A²+B²)/2 + q*(A*cos(k*x)+B*sin(k*x))
P_total = p + k*(A*PB-B*PA)
mu = a*V/2
omega² = (epsilon*k²+s)/a
```

`mu` — модальная инерция, а не масса тела; `PA=mu*A_t`, `PB=mu*B_t`.
Поле имеет два динамических коэффициента, поэтому может принять отдачу.
Стенд допускает движение центра тела по неограниченной координате x;
энергия взаимодействия периодична. Поле с бесконечным числом мод и
точечным самодействием этим приближением не моделируется.

Шаг kick–drift–kick использует производные одной энергии H:

```text
p_t = q*k*(A*sin(k*x)-B*cos(k*x))
PA_t = -mu*omega²*A-q*cos(k*x)
PB_t = -mu*omega²*B-q*sin(k*x)
x_t = p/m; A_t = PA/mu; B_t = PB/mu
```

Каждый kick сохраняет суммарный импульс за счёт равной отдачи;
каждый drift сохраняет его за счёт вращательной симметрии модальной
кинетической энергии. Интегратор второго порядка сохраняет импульс
с точностью округления, а энергию — приближённо. Нельзя скрывать
энергетическую ошибку нормировкой состояния после шага.

```bash
cargo run --release -p manonica-simulator --bin field_momentum
cargo test -p manonica-simulator --bin field_momentum
```

Тесты `LAW-MECH-001..004`: аналитическая отдача одного kick;
свободное тело и точный гармонический осциллятор при q=0;
сохранение полного импульса на каждом шаге, второй порядок энергии;
ковариантность при переносе координат и обратимость по времени.
Стенд использует фиксированные допустимые параметры и не предоставляет
публичного API механического решателя или пользовательской конфигурации.

## Следующие условия интеграции

- Типизированное поступательное состояние и внешний реестр введены
  отдельно от существующего микроскопического `Manon` без массы;
  модальные коэффициенты исследовательского стенда пока скалярные.
- До выбора сетки определить дискретную симметрию переноса: обычная
  интерполяция движущегося источника на неподвижную сетку не гарантирует
  точного сохранения импульса. Отдельно проверить самосилу и отдачу сетки.
- Выбрать сглаженное ядро объекта и проверить независимость результатов
  от его разрешения, размеров области и модального/сеточного отсечения.
- Внешняя предписанная сила и реестр импульса/работы уже проверены.
  Далее связать механику с теплом, захватом и освобождением манонов;
  динамические тела-опоры и контакты пока не моделируются.
- Только после этих эталонов включать общий механический шаг в Lab,
  GPU и Minecraft. Текущий `FieldLedger` механического импульса не хранит.

## Типизированное тело и внешняя нагрузка

`manonica-core` определяет единицы `Kilograms`,
`KilogramMetresPerSecond`; сила использует существующие `Newtons`.
`manonica-physics::MechanicalBody` хранит положительную массу,
3D-положение и импульс с закрытыми полями. Кинетическая энергия
`K=p·p/(2m)` вычисляется отдельно от энергии микроскопического `Manon`.
Метод `apply_impulse` применяет импульс при фиксированном положении
и возвращает знаковую работу `J·(p_before+J/2)/m`.
Внутренние взаимодействия должны учесть противоположный импульс партнёра.

`ExternalLoadLedger` хранит суммарный вектор импульса и знаковую работу,
доставленные внешним агентом в отслеживаемую систему. Внешняя опора
получает противоположный импульс; положительная работа уменьшает её
энергетический запас. Отрицательная работа описывает отбор энергии.
`advance_constant_force` выполняет точный свободный шаг при постоянной
внешней силе, `p1=p0+F*dt`, `x1=x0+dt*(p0+F*dt/2)/m`.
Это метод свободного тела, а не интегратор сил поля.
Все изменения тела и реестра транзакционны, включая переполнение
накопленного реестра при допустимом состоянии тела.

Нагруженный стенд `field_momentum` обрамляет прежний внутренний шаг
двумя половинными внешними импульсами через этот типизированный API.
При фиксированном положении изменение кинетической энергии равно
работе внешнего импульса, взаимодействие с полем при этом не меняется.
Проверяемые балансы:

```text
P_total(t)-P_total(0) = J_external
H(t)-H(0)-W_external = numerical_integration_error
```

При силе 0.1 Н за 5 секунд импульс внешнего агента равен 0.5 кг·м/с.
При 100/200/400 шагах энергетическая невязка уменьшается со вторым
порядком; на 400 шагах <0.001 Дж. Внешний агент задан реестром, а не
отдельным динамическим телом. Ввод нагрузок в Lab, контакты, вращение
материального тела и изменение его массы пока отсутствуют.
