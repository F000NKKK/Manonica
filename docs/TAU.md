# Универсальная библиотека ТАУ Manonica

## Принцип разделения

`manonica-control` не зависит от `manonica-physics`: объект управления может быть маноновым полем, магическим резонатором или любой другой динамической моделью.

Библиотека задаёт базовые структуры ТАУ, но **ещё не является полной математической реализацией всей теории автоматического управления**.

## Общие типы

- `Quantity<U>`: величина с единицей измерения `U`. Типы `Joules` и `Newtons` несовместимы на уровне Rust.
- `Time` и `TimeStep`: момент времени и строго положительная длительность.
- `Signal<U>`: значение сигнала заданной размерности в момент `Time`.
- `Gain<In,Out,Mode>`: коэффициент преобразования типизированного входа в выход. `ProportionalMode`, `IntegralMode`, `DerivativeMode` предотвращают смешение коэффициентов П, И и Д.
- `ControllerTerm<In,Out>`: обновление отдельного управляющего звена.
- `DynamicSystem<In,Out>`: численный шаг системы управления.

Указание `Mode` различает временные размерности коэффициентов П/И/Д **по назначению**. Универсальные алгебраические преобразования всех физических размерностей пока не реализованы.

## Сигналы

Все источники независимы и могут объединяться через `Sum`, `Scale`, `Delay`.

| Тип | Математическая модель |
| --- | --- |
| `Constant` | `y(t)=C` |
| `Step` | `y(t)=a` при `t<t0`, иначе `b` |
| `Ramp` | `y(t)=a+k(t-t0)` |
| `Sine` | `y(t)=offset+A sin(2πft+φ)` |
| `Square` | Периодический прямоугольный сигнал |
| `Pulse` | Одиночный прямоугольный импульс |
| `Triangle` | Треугольная волна |
| `Sawtooth` | Пилообразная волна |
| `Exponential` | Экспоненциальный переход |
| `DampedSine` | Затухающая синусоида |
| `Chirp` | ЛЧМ, частота линейно меняется на интервале |
| `Gaussian` | Гауссов импульс |
| `SampledNoise` | Воспроизводимый дискретный шум с seed |

Это реальные функции времени, а не команды запуска заклинания.

## П/И/Д

Блоки `Proportional`, `Integral` и `Derivative` реализуют `ControllerTerm` отдельно и компонуются в `Pid`. Интегратор использует правило трапеций; дифференциатор поддерживает фильтр 1-го порядка; ПИД поддерживает ограничение выхода и условное прекращение нарастания интегратора при насыщении.

`ControllerSnapshot` отражает внутренние состояния для диагностики, **но не определяет математическую наблюдаемость**.

## Пространство состояний

`LinearSystem<X,U,Y>` задаёт:
```text
x' = A*x + B*u
y  = C*x + D*u
```
Дискретный шаг системы пока реализован методом Эйлера.

### Управляемость и наблюдаемость

Критерий Калмана для управляемости:
```text
rank([ B  AB  A²B  ...  A^(n-1) B ]) = n
```
Для наблюдаемости:
```text
rank([C; CA; CA²; ...; CA^(n-1)]) = n
```
Численный ранг вычисляется через исключение Гаусса с заданным порогом. Для плохо обусловленных моделей необходим более устойчивый метод (SVD или QR).

### Наблюдатель Луенбергера

`LuenbergerObserver` оценивает скрытое состояние по измерению:
```text
xhat' = A*xhat + B*u + L*(y_measured - C*xhat - D*u)
```
Матрица `L` типизирована по размерности корректирующего воздействия. Наблюдатель возвращает оценку состояния и невязку измерения. При ошибке измерений состояние не изменяется.

## Ограничения, которые нельзя скрывать

1. Все компоненты вектора состояния `x` пока имеют **одну и ту же** единицу измерения `X`. Для модели «положение + скорость» требуется гетерогенное типизированное состояние.
2. Явный Эйлер и простой алгоритм ранга — прототипные численные методы, не универсальный численный анализ.
3. ТАУ пока не включает функции Лапласа, преобразование передаточных функций, Bode/Nyquist, оптимальное управление, дискретные фильтры Калмана, нелинейные наблюдатели и MPC.
4. Контроллеры являются компонентами; их настройка не задаёт автоматически устойчивость объекта.

## Следующие интерфейсы

- Нелинейные и гибридные системы.
- Переход между передаточными функциями и пространством состояний.
- Частотная диагностика и анализ устойчивости.
- Неоднородные типизированные физические состояния.
- Разные методы интегрирования (в том числе неявные).
- MPC, LQR и фильтр Калмана при подтверждённой потребности.
