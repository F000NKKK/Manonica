## Измерения на целевом GPU — 2026-11-13

Источник: вывод запусков пользователя на NVIDIA GeForce RTX 4050 Laptop GPU,
Vulkan, release. Результаты относятся к указанным сценариям.

Кадровая трасса `local_boundary_conductor.toml`, окно 1280×800, FIFO VSync:
8230 кадров после исключения 10 секунд прогрева.

| Стадия, мс | p50 | p95 | max |
| --- | ---: | ---: | ---: |
| Интервал кадра | 6.941 | 8.156 | 13.006 |
| Render | 6.936 | 8.150 | 13.000 |
| Ввод | 0.001 | 0.001 | 0.093 |
| Обновление | 0.001 | 0.197 | 0.391 |
| Оверлеи | 0.002 | 0.009 | 0.475 |
| Draw/present | 6.903 | 8.124 | 12.988 |

Время преимущественно приходится на draw/present, включающий ожидание
представления. Трасса сама по себе не разделяет работу GPU и ожидание VSync.

Полный связанный стенд:
`cargo run --release -p manonica-simulator --features gpu --bin gpu-coupled -- --grid 32 24 32 --steps 120 --batch 3`.
24576 ячеек, 120 измеренных шагов после одного прогревочного, 40 снимков.

- CPU: 533.009 мс; GPU end-to-end: 97.463 мс; ускорение около 5.47×.
- Пакет до 3 шагов: p50 2.350 мс, p95 3.386 мс; среднее 0.812 мс/шаг.
- Максимальная ошибка свободной плотности: 9.132e-6.
- Максимальная ошибка связанного запаса/тепла: 2.142e-6.
- Ошибка количества манонов: 1.383e-3 (абсолютная, вывод стенда).
- Максимальная ошибка энергетического учёта: 9.725e-7.
- Проверки стенда прошли; `shutdown true`.

Эти замеры подтверждают текущий сценарий на целевом устройстве;
универсальная эквивалентность законов и производительность других сеток
требуют собственных проверок.
