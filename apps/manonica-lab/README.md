# Manonica Lab

Графическая лаборатория для воспроизводимых физических экспериментов.
Рендеринг через **Meridian SDK → WGPU**. Используются только публичные
экспорты `meridian-sdk`, без прямых импортов низкоуровневых крейтов движка.

## Запуск

```bash
cd apps/manonica-lab
cargo run --release
cargo run --release -- experiments/two_sources.toml
cargo test
```

Приложение находится в **отдельной Cargo workspace**, чтобы графические
драйверы, аудио и окружение Meridian не подключались к базовым тестам
численной физики `cargo test --workspace` из корня Manonica.

Используется **Meridian SDK 0.8.0**, закреплённый на коммите
`cf950f21572663aeb5077861b2a95d4f2d111427` (Git revision).
Пока отдельный GitHub-тег `v0.8.0` недоступен, привязка к полному SHA
сохраняет воспроизводимость. После публикации тега эту привязку можно
заменить на `tag = "v0.8.0"` с отдельной проверкой.

## Управление

| Клавиши | Действие |
|---|---|
| WASD + мышь | Полёт камеры |
| Escape | Захват / освобождение указателя |
| Space | Пауза / продолжение |
| R | Вернуть начальное распределение и время 0 |
| F | Включить / выключить декоративные вихри |
| Стрелки вверх/вниз | Порог отображаемой плотности |

## Устройство

- `experiment/` — TOML-схема, валидация, типизированный
  `ExperimentBuilder`, доменные ошибки
- `simulation/` — сохранение числа манонов, сборка поля из
  нормированных начальных распределений и вызов `FreeDiffusion`
- `visualization/` — геометрия окружностей и визуальное
  отображение реальной плотности из `FreeManaField`
- `app.rs` — жизненный цикл и камера Meridian SDK

`seeds` определяют **только начальное количество** свободных манонов:
каждая форма распределяет свой `total_manons` по сетке с нормировкой на
объём ячейки. Круги — пока **геометрические конструкции**, которые не
создают манонов и не меняют физические законы. Любые будущие связи
кругов с полями должны быть реализованы через общие законы
в `manonica-physics`, без знания типов высокоуровневых конструкций.

Декоративный эффект `wisps` тоже не влияет на симуляцию.
На данном этапе отображение использует 3D-меши выборок плотности,
с окраской и bloom. Это **не** полноценный объёмный
ray-marching: 3D-текстура и отдельный рендер-проход потребуют
расширения публичного интерфейса Meridian SDK.

Для добавления своего эксперимента скопируй один из TOML-файлов
в `experiments/`. Параметры диффузии являются калибруемыми,
а не константами игрового мира.
