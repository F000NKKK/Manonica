# Физические пакеты GPU-механики, RTX 4050 — 2026-11-14

Три прогона при работающем FTB Minecraft и три после подтверждённого
пользователем закрытия. Запуск без окна, атласа поля и рендера Lab.
Параметры идентичны: 2 тела, 171 пара мод, cutoff=3, dt=0.005 с,
100 шагов прогрева, 3000 измеренных шагов пакетами по 10.

```bash
cargo run --release -p manonica-simulator --features gpu --bin gpu-mechanics -- \
  --steps 3000 --batch 10 --warmup 100 --label ftb-loaded-01 --csv /tmp/mechanics-loaded-01.csv
```

Для второй серии изменяются только label и выходной файл. Существующий
CSV не перезаписывается. В каждом прогоне 300 независимых пакетов;
итоговые квантили ниже вычислены по объединённым 900 пакетам одного режима
линейной интерполяцией между соседними порядковыми статистиками.

| --- | ---: | ---: | ---: | ---: | ---: |
| FTB работает | 1.642439 | 2.525224 | 2.885126 | 3.423205 | 0.172274 |

При FTB среднее время шага выше на 18.6%, p95 пакета — на 42.7%,
p99 — на 45.2%. Измеряется wall time полного принятого пакета:
GPU submission, ожидание, readback и проверка снимка на CPU. Это не
GPU timestamp отдельных ядер. Запись CSV буферизована; время отдельного
пакета измерено до записи его строки.

CPU-эталон считается отдельно до GPU-измерений. На этой маленькой сцене
CPU быстрее полного GPU-пути: нельзя заявлять ускорение GPU или переносить
эти времена на мини-мир с тысячей чанков. Накладные расходы устройств и
снимков существенны для двух тел.

Все шесть прогонов прошли аудит. Максимальные расхождения CPU/GPU:
координаты/импульсы тел 4.271133e-6, моды 4.335083e-7,
энергия 6.256764e-8 Дж, компонента импульса 3.589888e-7.

Перед серией с FTB: GPU 39%, P5, 495 МГц, 275 MiB. Перед серией без
FTB: 0%, P8, 210 МГц, 93 MiB; процессов java и manonica-lab в проверке
не было. Это мгновенные предварительные наблюдения, не средние значения
за замер. Частоты не фиксировались; DVFS, планирование CPU/GPU и порядок
серий могут влиять на результаты. Прогоны короткие и не рандомизированы;
доверительные интервалы и длительная тепловая стабилизация не исследованы.

Исходные 6 CSV находятся рядом с этим файлом, параметры и сводка —
