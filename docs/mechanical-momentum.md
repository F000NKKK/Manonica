# Механика: динамическое скалярное поле и импульс

Статус: математический контракт и экспериментальный одномерный стенд.
Сетка Lab остаётся квазистатической; механическая сила на блоки ещё
не реализована. Коэффициенты ниже — параметры исследуемой модели.

## Почему одного дрейфа недостаточно

Закон `J=-M*n*grad(phi)` описывает перенос концентрации в среде.
Он не задаёт массу, скорость ускоряемого тела или импульс поля.
Поле Lab создаётся заданными источниками и условиями на границе;
их опоры могут обмениваться импульсом с внешним миром. Приписывать
этой открытой системе сохранение импульса без учёта опор нельзя.

Для закрытого стенда примем динамическое поле с лагранжианом

```text
L = sum_a m_a*|v_a|²/2
    + integral( a*phi_t²/2 - epsilon*|grad(phi)|²/2 - s*phi²/2 ) dV
    - sum_a q_a*phi(X_a)
```

`phi` измеряется в Дж/манон, `q` — в манонах, `m` — в кг,
`s` и `epsilon` имеют те же размерности в плотности энергии, что и
квазистатическая модель. `a` имеет размерность
`Дж*с²/(м³*(Дж/манон)²)` и задаёт инерционность поля.
Заряды здесь фиксированы; обмен свободными/связанными манонами
в эту механическую модель пока не включён.

Уравнения вариационной модели:

```text
a*phi_tt - epsilon*laplacian(phi) + s*phi = -rho_q
rho_q(x) = sum_a q_a*delta(x-X_a)
m_a*X_a_tt = -q_a*grad(phi)(X_a)
```

Для распределённого объекта дельта заменяется нормированным ядром,
а сила вычисляется производной той же энергии взаимодействия по X.
Знак правой части важен: в статическом пределе существующий `source`
соответствует `-rho_q`. Существующие источники Lab автоматически
не становятся механическими зарядами.

В периодической замкнутой области:

```text
P_body = sum_a m_a*v_a
P_field = -integral( a*phi_t*grad(phi) ) dV
P_total = P_body + P_field
H = sum_a m_a*|v_a|²/2
    + integral( a*phi_t²/2 + epsilon*|grad(phi)|²/2 + s*phi²/2 ) dV
    + sum_a q_a*phi(X_a)
```

Из уравнений `dP_body/dt=-integral(rho_q*grad(phi))dV`,
`dP_field/dt=+integral(rho_q*grad(phi))dV`; поэтому `dP_total/dt=0`.
Для непериодической области добавляются потоки напряжений через границу,
реакции опор, внешний импульс и работа. Они должны попасть в отдельный
реестр до включения неподвижных источников или внешней нагрузки.

## Независимый двухмодовый стенд

`apps/manonica-simulator/src/bin/field_momentum.rs` ограничивает поле
одной парой Фурье-мод на периоде `L=2*pi/k`:

```text
phi(x) = A*cos(k*x) + B*sin(k*x)
H = p²/(2m) + (PA²+PB²)/(2*mu)
    + mu*omega²*(A²+B²)/2 + q*(A*cos(k*x)+B*sin(k*x))
P_total = p + k*(A*PB-B*PA)
mu = a*V/2
omega² = (epsilon*k²+s)/a
```

`mu` — модальная инерция, а не масса тела; `PA=mu*A_t`, `PB=mu*B_t`.
Поле имеет два динамических коэффициента, поэтому может принять отдачу.
Стенд допускает движение центра тела по неограниченной координате x;
энергия взаимодействия периодична. Поле с бесконечным числом мод и
точечным самодействием этим приближением не моделируется.

Шаг kick–drift–kick использует производные одной энергии H:

```text
p_t = q*k*(A*sin(k*x)-B*cos(k*x))
PA_t = -mu*omega²*A-q*cos(k*x)
PB_t = -mu*omega²*B-q*sin(k*x)
x_t = p/m; A_t = PA/mu; B_t = PB/mu
```

Каждый kick сохраняет суммарный импульс за счёт равной отдачи;
каждый drift сохраняет его за счёт вращательной симметрии модальной
кинетической энергии. Интегратор второго порядка сохраняет импульс
с точностью округления, а энергию — приближённо. Нельзя скрывать
энергетическую ошибку нормировкой состояния после шага.

```bash
cargo run --release -p manonica-simulator --bin field_momentum
cargo test -p manonica-simulator --bin field_momentum
```

Тесты `LAW-MECH-001..004`: аналитическая отдача одного kick;
свободное тело и точный гармонический осциллятор при q=0;
сохранение полного импульса на каждом шаге, второй порядок энергии;
ковариантность при переносе координат и обратимость по времени.
Стенд использует фиксированные допустимые параметры и не предоставляет
публичного API механического решателя или пользовательской конфигурации.

## Следующие условия интеграции

- Типизированное поступательное состояние и внешний реестр введены
  отдельно от существующего микроскопического `Manon` без массы;
  модальные коэффициенты исследовательского стенда пока скалярные.
- До выбора сетки определить дискретную симметрию переноса: обычная
  интерполяция движущегося источника на неподвижную сетку не гарантирует
  точного сохранения импульса. Отдельно проверить самосилу и отдачу сетки.
- Выбрать сглаженное ядро объекта и проверить независимость результатов
  от его разрешения, размеров области и модального/сеточного отсечения.
- Внешняя предписанная сила и реестр импульса/работы уже проверены.
  Далее связать механику с теплом, захватом и освобождением манонов;
  динамические тела-опоры и контакты пока не моделируются.
- Только после этих эталонов включать общий механический шаг в Lab,
  GPU и Minecraft. Текущий `FieldLedger` механического импульса не хранит.

## Типизированное тело и внешняя нагрузка

`manonica-core` определяет единицы `Kilograms`,
`KilogramMetresPerSecond`; сила использует существующие `Newtons`.
`manonica-physics::MechanicalBody` хранит положительную массу,
3D-положение и импульс с закрытыми полями. Кинетическая энергия
`K=p·p/(2m)` вычисляется отдельно от энергии микроскопического `Manon`.
Метод `apply_impulse` применяет импульс при фиксированном положении
и возвращает знаковую работу `J·(p_before+J/2)/m`.
Внутренние взаимодействия должны учесть противоположный импульс партнёра.

`ExternalLoadLedger` хранит суммарный вектор импульса и знаковую работу,
доставленные внешним агентом в отслеживаемую систему. Внешняя опора
получает противоположный импульс; положительная работа уменьшает её
энергетический запас. Отрицательная работа описывает отбор энергии.
`advance_constant_force` выполняет точный свободный шаг при постоянной
внешней силе, `p1=p0+F*dt`, `x1=x0+dt*(p0+F*dt/2)/m`.
Это метод свободного тела, а не интегратор сил поля.
Все изменения тела и реестра транзакционны, включая переполнение
накопленного реестра при допустимом состоянии тела.

Нагруженный стенд `field_momentum` обрамляет прежний внутренний шаг
двумя половинными внешними импульсами через этот типизированный API.
При фиксированном положении изменение кинетической энергии равно
работе внешнего импульса, взаимодействие с полем при этом не меняется.
Проверяемые балансы:

```text
P_total(t)-P_total(0) = J_external
H(t)-H(0)-W_external = numerical_integration_error
```

При силе 0.1 Н за 5 секунд импульс внешнего агента равен 0.5 кг·м/с.
При 100/200/400 шагах энергетическая невязка уменьшается со вторым
порядком; на 400 шагах <0.001 Дж. Внешний агент задан реестром, а не
отдельным динамическим телом. Ввод нагрузок в Lab, контакты, вращение
материального тела и изменение его массы пока отсутствуют.

## Многомодовая дискретизация и сглаженный объект

Стенд `spectral_field` расширяет поле до M пар мод на периоде 2*pi м:
`phi=sum_j(A_j*cos(j*x)+B_j*sin(j*x))`, `j=1..M`.
Выбран периодический нормированный гауссов объект ширины sigma;
его форм-фактор `g_j=exp(-(j*sigma)²/2)`. Один и тот же множитель
используется в возбуждении мод, энергии взаимодействия и силе:

```text
H_int = sum_ij q_i*g_ij*(A_j*cos(j*x_i)+B_j*sin(j*x_i))
F_i = sum_j q_i*g_ij*j*(A_j*sin(j*x_i)-B_j*cos(j*x_i))
PA_j_t = -(j²+1)*A_j - sum_i q_i*g_ij*cos(j*x_i)
PB_j_t = -(j²+1)*B_j - sum_i q_i*g_ij*sin(j*x_i)
P_total = sum_i p_i + sum_j j*(A_j*PB_j-B_j*PA_j)
```

Параметры поля нормированы так, что модальная инерция равна 1,
`omega_j²=j²+1`. Тела используют типизированный `MechanicalBody`;
добавлен транзакционный `advance_free` для дрейфа при постоянном импульсе.
Шаг системы — kick–drift–kick с одним кандидатом для всех тел и мод:
отказ не оставляет частично обновлённые тела или поле.

Нулевая мода исключена: стенд описывает поле с нулевым средним.
В динамическом опыте заряды +0.4 и -0.4 суммарно нейтральны.
Однообъектные статические тесты соответствуют компенсирующему
однородному фону; это не изолированный заряд в бесконечном пространстве.

Для одного неподвижного объекта статическое решение
`A_j=-q*g_j*cos(j*x)/(j²+1)`,
`B_j=-q*g_j*sin(j*x)/(j²+1)` даёт F=0 при любой фазе x.
Оно проверяется при 1/4/16/32 модах, sigma=0.2/0.35/0.6 и пяти
положениях. Это отсутствие **статической** самосилы в выбранной
спектральной дискретизации; движущийся источник может обмениваться
импульсом со своим динамическим полем.

Для пары статических источников проверяются равенство и противоположность
сил и инвариантность энергии/силы при общем переносе координат.
Статическая энергия одного объекта равна
`-q²/2*sum_j exp(-sigma²*j²)/(j²+1)`.
Остаток после M мод ограничен геометрической суммой:

```text
|tail| <= q²/2 * exp(-sigma²*(M+1)²)/((M+1)²+1)
          / (1-exp(-sigma²*(2*M+3)))
```

Это независимая оценка ошибки отсечения; тесты проверяют её при
M=2/4/8/16 по сравнению с 64 модами. Для sigma=0.35 при 16 модах
ошибка энергии <1e-12 Дж.

В динамическом опыте за 1 с с 16 модами полный импульс проверяется
на каждом шаге с допуском 1e-11 кг·м/с. При 100/200/400 шагах
энергетическая ошибка убывает в 3.8–4.2 раза. На 400 шагах она
<1e-5 Дж. При одинаковом dt координаты и импульсы обоих тел при
8 и 16 модах отличаются от опыта с 32 модами менее чем на 1e-5
и 1e-11 соответственно. Это проверка модального отсечения при
фиксированных ширине, периоде и времени, а не исследование всех
пространственных масштабов.

```bash
cargo run --release -p manonica-simulator --bin spectral_field
cargo test -p manonica-simulator --bin spectral_field
```

Тесты LAW-SPECTRAL-001..004 включены в workspace. Предпочтение спектральному
подходу на этом стенде связано с точной симметрией непрерывного переноса:
нет фазы объекта относительно неподвижных узлов интерполяции. Период и ширина ядра исследованы в одномерном стенде ниже. Выбор
трёхмерного backend, поведение на непериодических границах и физическая
калибровка sigma ещё не завершены.
Движение, захват и тепло Lab пока не связаны с этим полем.

## Период области и физическая ширина ядра

`spectral_field` допускает внутреннюю настройку длины L. При её
изменении физические коэффициенты фиксированы:
`a=epsilon=s=1/pi`, `k_j=2*pi*j/L`, `mu=L/(2*pi)`,
`omega_j²=k_j²+1`. Кинетическая энергия каждой моды
`(PA²+PB²)/(2*mu)`, потенциальная — `mu*omega²*(A²+B²)/2`;
скорости мод `A_t=PA/mu`, `B_t=PB/mu`.
Без изменения mu вместе с L сравнивались бы разные физические среды.
Публичного конфигурируемого API пока нет; стенд проверяет параметры
области, число мод 1..4096 и положительность конечной ширины ядра.

`LAW-SPECTRAL-005` сравнивает статическую силу с независимым расчётом
в координатном пространстве. Для бесконечной области
`G(r)=pi/2*exp(-|r|)` — функция Грина оператора
`(-d²/dx²+1)/pi`. Сила на первый источник:

```text
F1 = q1*q2 * integral G'(r+z)*Normal(z;0,w²) dz
r = x1-x2; w² = sigma1²+sigma2²
```

Интеграл разбит в точке излома G' и вычисляется правилом Симпсона.
Периодический эталон получен суммированием образов с номерами -4..4.
Он не вызывает спектральный решатель. Влияние конечных пределов
интегрирования и суммы подавлено экспоненциальными хвостами;
для основного интеграла сравниваются 4096/8192 интервалов с допуском
1e-10 Н. При `q1=0.4`, `q2=-0.4`, расстоянии 1.6 м и
`sigma=0.2/0.35/0.6 м` спектральная и периодическая координатная
силы совпадают с допуском 1e-9 Н.

Периоды `2*pi`, `4*pi`, `8*pi м` используют 64/128/256 мод,
сохраняя максимальное физическое волновое число. Разность с силой
бесконечной области убывает и ограничена оценкой периодических образов:

```text
|F_L-F_infinite| <= 2*pi*|q1*q2|*exp(sigma²)*cosh(r)
                    *exp(-L)/(1-exp(-L))
```

При L=8*pi измеренная разность <1e-9 Н. Это проверка статической
экранированной силы; она не доказывает отсутствие динамических возвратов
волн через периодическую границу на произвольном времени.

`LAW-SPECTRAL-006`: при L=8*pi и sigma=0.2/0.1/0.05 м число мод
растёт как 32/sigma. Сила приближается к точечному эталону
`-0.16*pi/2*exp(-1.6) Н` со вторым порядком по sigma; отношение
ошибок 3.8–4.2, абсолютная ошибка при sigma=0.05 <0.0002 Н.
Изменение sigma меняет физическую форму объекта, поэтому эта проверка
не является основанием выбирать ширину ради ускорения вычислений.

Дополнительно на периодах 2*pi и 4*pi при sigma=0.2/0.6 проверены
динамический импульс и энергия на каждом из 400 шагов за секунду.
Допуски — 1e-11 кг·м/с и 1e-5 Дж. Отрицательные тесты отвергают
недопустимые периоды, ширины и число мод. Все проверки включены
в `cargo test --workspace`, а основной запуск стенда выводит таблицу
сил для разных L/sigma после проверки временной сходимости.

## Трёхмерный спектральный стенд

`src/bin/spectral_field/three_dimensional.rs` расширяет тот же численный
код мод и сил до векторных `k` и типизированного трёхмерного тела.
Каждая пара мод использует `cos(k·X)`/`sin(k·X)`, частоту
`omega²=|k|²+1` и гауссов форм-фактор `exp(-sigma²*|k|²/2)`.
Сила равна сумме `q*g*k*(A*sin(k·X)-B*cos(k·X))`;
полевой импульс — `sum k*(A*PB-B*PA)`, вектор по всем трём осям.

На периодическом кубе со стороной 2*pi и `a=epsilon=s=1/pi`
модальная инерция равна `a*V/2=4*pi²`. Используется кубическое
отсечение целочисленных векторов `[-K,K]³`. Нулевой вектор исключён;
из пары +/-k берётся только вектор с положительной первой ненулевой
компонентой. Одна косинусная/синусная пара уже представляет оба знака,
поэтому число пар `((2K+1)³-1)/2`. Это предотвращает двойной учёт энергии.

Проверки LAW-SPECTRAL-3D-001..004:

- При K=1/3/6 проверяются число уникальных пар, отсутствие противоположных
  дублей и статическая самосила по всем осям с допуском 1e-14 Н.
- Наклонная мода `k=[1,2,-1]`, A=0, B=2 и объект в начале координат
  дают аналитическую силу `-0.8*g*k`. За kick=0.25 с объект получает
  `-0.2*g*k`, поле — противоположный импульс (допуск 1e-13 кг·м/с).
- Для пары заряженных объектов с несовпадающими координатами по всем осям
  проверены противоположность сил, симметрия общего переноса и циклическая
  перестановка координат для полного трёхмерного расположения тел.
- Сила сравнивается с центральной разностью полной статической энергии
  при смещении одного объекта по каждой оси на +/-1e-5 м. Допуск 1e-10 Н;
  поле переустанавливается в статическое равновесие при каждом смещении.
- В динамическом опыте K=3 (171 пара), sigma=0.6 м, два противоположных
  заряда +/-0.4 с ненулевыми скоростями по всем осям: за 1 секунду
  с 100/200/400 шагами проверяется полный векторный импульс
  (максимальная ошибка компоненты <1e-11 кг·м/с) и второй порядок
  энергетической ошибки (отношение 3.8–4.2, ошибка на 400 шагах <1e-6 Дж).
- Статическая сила при K=2/4/6/8 приближается к эталону K=10;
  ошибка максимальной компоненты убывает, на K=8 меньше 1e-11 Н.
  Это проверка отсечения при фиксированных периоде и sigma, а не
  независимый координатный эталон трёхмерного закона.

Отрицательные тесты отвергают K вне диапазона 1..12 и проверяют отказ
при переполнении без частичного обновления тел/мод. Основной запуск
`spectral_field` теперь выводит также таблицу 3D-временной сходимости.

Конечное кубическое отсечение сохраняет симметрии перестановки осей,
но не гарантирует точную инвариантность относительно произвольного
поворота. Независимая координатная сила 3D и изменение периода/ядра проверены
в следующем разделе. Пока не проверены непериодические границы
и динамическое отсечение траекторий по K. Стенд остаётся CPU-экспериментом; он не подключён к Lab,
GPU или Minecraft и не заменяет существующий квазистатический backend.

## Независимая координатная сила в 3D

`LAW-SPECTRAL-3D-005` сравнивает спектральную силу с координатной
свёрткой экранированной функции Грина и двух гауссовых объектов.
При выбранных коэффициентах `G(r)=exp(-r)/(4*r)`. Для одинаковой
ширины sigma свёртка представляется интегралом теплового ядра:

```text
u = t + sigma²
G_sigma(r) = pi * integral_0^infinity
    exp(-t-|r|²/(4u)) / (4*pi*u)^(3/2) dt
F(r) = -q1*q2*pi*r/2 * integral_0^infinity
    exp(-t-|r|²/(4u)) / ((4*pi*u)^(3/2)*u) dt
```

`t` — вспомогательный параметр интеграла, не физическое время шага.
Формулы записаны в нормировке с длиной экранирования 1 м.
Расстояние источников задано вектором `[-1.6,-1.1,-2.1] м`,
заряды +0.4/-0.4, ширины 0.6/0.8/1.0 м.
Координатный код не вызывает спектральные поля, силы или энергию.

Сравниваются кубические периоды `L=2*pi`, `3*pi`, `4*pi м`
с отсечениями K=8/12/16. При изменении L волновые числа
`k=2*pi*j/L`, модальная инерция `mu=L³/(2*pi)`.
Физическое максимальное волновое число сохраняется.
Для всех девяти случаев проверяются максимальные расхождения компонент:

- K и K+2: <1e-9 Н, контроль спектрального отсечения;
- 4096 и 8192 интервала Симпсона на `[0,64]`: <1e-10 Н;
- координатные образы в кубах `[-2,2]³` и `[-3,3]³`: <1e-9 Н;
- спектральная и уточнённая координатная силы: <1e-8 Н.

Интегральный хвост подавлен `exp(-t)`, хвост суммы образов —
экранированием. Разности уточнений — практический контроль эталона,
а не строгая универсальная оценка остатка для произвольных параметров.
При увеличении периода максимальная компонентная разность с
бесконечной областью уменьшается не менее чем в пять раз на каждом
шаге. В текущих опытах она меняется примерно от 1.1e-4–1.9e-4 Н
при L=2*pi до 1.2e-7–2.2e-7 Н при L=4*pi. Это физическое влияние
периодических образов, а не ошибка спектрального решения.

Независимая проверка координатного эталона: при sigma=0.2/0.1/0.05
свёртка стремится ко векторной точечной силе
`-q1*q2/4*exp(-r)*(1/r²+1/r³)*r_vector`.
Отношение ошибок 3.8–4.2 подтверждает второй порядок по ширине.
На самой узкой гауссиане относительная ошибка ограничена
`2*sigma²`; вдали от начала координат это следует из
`exp(sigma²)-1 < 2*sigma²` для выбранных ширин и единицы длины.

Проверяются недопустимые периоды/отсечения и переполнение объёма.
Основной `spectral_field` выводит и эту таблицу. Результаты остаются
статическими: вывод о динамических возвратах волн, всех направлениях
вращения или пригодности конфигурации для произвольного 3D-мира
из этих опытов не следует.

## Переиспользуемый экспериментальный API

Численное ядро перенесено в
`crates/manonica-physics/src/mechanics/spectral.rs`. Стенд `spectral_field`
вызывает этот API; локальные адаптеры только переводят наблюдения в
формат вывода и сохраняют независимые координатные эталоны.

- `GaussianBody`: типизированное `MechanicalBody`, знаковый заряд в
  манонах и ширина в метрах. Заряд/ширина валидируются при создании
  решателя, источники внутри состояния недоступны для прямого изменения.
- `PeriodicSpectralDomain::new(lengths, cutoff)`: прямоугольный период
  с типизированными длинами и отдельным отсечением по осям. Нулевая
  мода исключена; полурешётка и инерция `V/(2*pi)` строятся вместе.
  Нулевое отсечение по двум осям задаёт одномерный набор мод при
  указанном поперечном объёме. Лимит — 65535 пар мод и 4096 по оси;
  недопустимый бюджет проверяется до выделения массива мод.
- `domain.static_equilibrium(sources)`: начальное статическое поле
  в положениях тел. Для модального исследования также доступен
  `SpectralMechanics::static_equilibrium(sources, waves, inertia)`:
  векторы должны быть уникальны и иметь положительную первую ненулевую
  компоненту. Дубли с различающимся знаком нуля тоже отвергаются.
- `advance(TimeStep)`: общий kick–drift–kick тела/поля. Выполняется
  необходимое условие устойчивости свободных мод `dt*omega_max<2`.
  Оно не гарантирует точность или устойчивость произвольной сильной
  связи: меньший шаг выбирается исследованием сходимости.
- `total_energy`, `total_momentum`, `force_on(index)`: конечные
  типизированные величины `Joules`, `KilogramMetresPerSecond`, `Newtons`.
  Суммарная энергия знаковая из-за энергии взаимодействия.
- `sources`, `modes`: чтение состояния без изменяемого доступа.
  `replace_mode_storage([[A,B,PA,PB],...])` атомарно заменяет только
  значения мод, сохраняет геометрию и проверяет конечность состояния.
  Это импорт снимка, а не доказательство сохранения энергии относительно
  предыдущего состояния; внешний backend должен выполнить такой аудит.
- `apply_external_impulse(index, impulse, ledger)`: общий атомарный
  коммит тела и `ExternalLoadLedger`. Импульс прикладывается при
  фиксированном положении, работа равна изменению кинетической энергии.
- `potential_kick(TimeStep)`: точный потенциальный подшаг при фиксированных
  положениях и A/B для численных опытов. Для полного шага используется
  `advance`; сам подшаг не является полным физическим интегрированием.

Пример инициализации (все величины — SI):

```rust
use manonica_core::{Quantity, TimeStep, Vec3};
use manonica_physics::{GaussianBody, MechanicalBody, PeriodicSpectralDomain};

let domain = PeriodicSpectralDomain::new(
    Vec3::try_values(6.0, 6.0, 6.0)?, [3, 3, 3],
)?;
let body = MechanicalBody::new(
    Quantity::new(2.0)?, Vec3::try_values(1.0, 2.0, 3.0)?,
    Vec3::try_values(0.0, 0.0, 0.0)?,
)?;
let mut system = domain.static_equilibrium(vec![GaussianBody {
    body, charge: 0.4, width: 0.6,
}])?;
system.advance(TimeStep::from_seconds(0.001)?)?;
let energy = system.total_energy()?;
let momentum = system.total_momentum()?;
```

Один заряд в этом примере означает компенсирующий однородный фон,
так как нулевая мода отсутствует. Это по-прежнему экспериментальный
CPU-решатель с фиксированными коэффициентами `a=epsilon=s=1/pi`,
без связи с полями концентрации, реакциями материалов или рендерером.
API не зависит от Lab, TOML, Meridian, WGPU и Minecraft.

`tests/spectral_mechanics.rs` проверяет входные ограничения, знаковые
нули и дубли мод, типизированные наблюдения при внешнем импульсе,
атомарный отказ снимка/шага/нагрузки и ограничение свободного шага.
Все прежние 1D/3D физические эталоны стенда выполняются через этот API.

## Подключение к Lab и GPU

`dynamic_mechanics.toml` подключает API отдельным опытом Lab: тела,
периодическое поле и наблюдения идут через общий worker. Конфигурация
отвергает смешивание с концентрациями, ловушками и прежним потенциалом.
На сцене отображаются маркеры положений; само динамическое поле пока
не визуализируется. F3 содержит общую энергию и импульс с отклонениями
от начального состояния. Метрики сгруппированы вложенными структурами
по времени, симуляции, запасу, материалам, полю, объёму и механике.

`GpuSpectral` из `manonica-compute-gpu` выполняет тот же шаг в WGSL
в f32, держит состояние между пакетами и импортирует проверенные снимки
через атомарный `SpectralMechanics::replace_snapshot`. Импорт сохраняет
массы, заряды, ширины и геометрию мод; глобальный баланс проверяет backend.
Параметр `--backend gpu` применим к механике и требует этого решателя.
CPU остаётся независимым f64-эталоном. Инициализация статического поля
и подготовка метаданных выполняются на CPU до резидентных шагов.

Проверены 100 шагов CPU/GPU в пяти резидентных пакетах, конечность и
балансы снимка, байтовое восстановление GPU-буферов при ошибке, пауза,
сброс, замена и остановка CPU/GPU-worker. GPU-тесты выполнены через
программный Vulkan llvmpipe; измерения на аппаратной RTX ещё нужны.
Подробности бюджетов аудита: [compute backends](compute-backends.md).
