# Первый слой магической физики

Принципы согласованы со спецификацией «Магическая инженерия v0.1», §§1–4, 19–20.

## Что именно моделируется сейчас

- `Manon` — отдельная свободная частица с ID, положением, скоростью и ресурсом энергии. `ParticleLaw` позволяет заменить закон движения.
- `ManonSystem` — коллекция для микроскопических исследований; обновление транзакционно.
- `FreeManaField` — концентрация свободных манонов на регулярной сетке 3D с физическим размером ячейки.
- `FreeDiffusion` — консервативный шаг диффузии по общим граням, с отражающими границами.
- `Evolution<State>` из core — общий контракт вычислительного шага.

## Минимальный закон

Для свободной маны:
```text
∂n/∂t + div(J) = S
J = -D∇n     (в первом эксперименте S=0)
```

Применяется конечно-объёмная схема. Каждая внутренняя грань даёт равные и противоположные изменения количества манонов в двух соседних ячейках. В мире нет внутренних «читерских» источников.

Достаточное условие устойчивости для 3D-кубической сетки с одинаковым шагом:
```text
D Δt / Δx² ≤ 1/6
```

Проверяется общий запас: `Σ_i n_i · Δx³`, не просто сумма концентраций.

## Чего сейчас **нет**

- Связывания и освобождения манонов.
- Материализации или дематериализации.
- Энергетического реестра всех каналов.
- Силовых и электроподобных взаимодействий.
- Влияния биологических органов и магической геометрии.
- Специальной физики кристаллов (её здесь и не должно быть).

Кристалл, манацит, руда или магическое устройство принадлежат будущим библиотекам предметных моделей. Они будут поставлять свойства ловушек, источники и граничные условия, а физический движок — решать только общие законы.

Численные коэффициенты не являются окончательными константами мира: их определим экспериментами.
