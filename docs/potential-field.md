# Этап A — расчёт магического потенциала

Реализация раздела 4.2–4.4 спецификации v0.1, не отдельное заклинание.

## Законы и приближение

В расчётной области строится скалярное поле `phi(x,y,z)` на
той же регулярной 3D-сетке, где уже хранятся свободные маноны.

Статический численный закон:

```text
- permittivity * laplacian(phi) + screening * phi = source
```

Это *экранированное квазистатическое приближение* из (4.4), а не
динамическое волновое поле. Численные коэффициенты калибруются как
параметры вымышленной физики мира Minecraft.

Полный поток свободной формы вычисляется разделёнными по времени
консервативными операторами:

```text
J = -D*grad(n) - mobility*n*grad(phi) + n*v_medium
```

- Диффузия `-D grad(n)` уже существовала.
- Перенос средой `n*v_medium` уже существовал.
- Новый градиентный оператор `-mobility*n*grad(phi)` выполняется
  в `crates/manonica-physics/src/field/potential.rs`.
- На каждой внутренней грани сумма манонов сохраняется точно с
  плавающей погрешностью. Внешние границы **для манонов** непроницаемы.
- Для градиентного потока используется upwind-схема с адаптивным
  подразделением шага, ограничением CFL, неотрицательными концентрациями.

## Источники: физика от математической конструкции

Источники формируются из `[[formulas]]` по тому же набору сегментов,
из которого строятся визуальная геометрия и материальные ловушки.
Каждый отрезок проходит растеризацию на ячейки с шагом не более
половины ширины ячейки.

`[[field_sources]]` содержит индекс геометрической формулы и
интегральную силу источника:

```toml
[[field_sources]]
formula = 0
strength = -200.0
```

Отрицательный источник создаёт потенциальную яму и притягивает свободные
маноны, положительный — отталкивает. Полная сила распределяется между
уникальными ячейками, не умножаясь от увеличения `segments`.

Пример в `apps/manonica-lab/experiments/potential_concentrator.toml`:

```toml
[physics.potential]
mobility = 0.18
permittivity = 1.0
screening = 0.6
boundary = "grounded"
iterations = 160
initial_work_joules = 20000.0
max_power_joules_per_second = 10000.0
```

`boundary`: `grounded` — нулевой внешний потенциал (Дирихле);
`insulated` — нулевой нормальный градиент на границе (Нейман).
`screening > 0` обеспечивает единственность решения без выбора
дополнительного калибровочного потенциала.

При отсутствии раздела `[physics.potential]` прежние эксперименты
рассчитываются без нового поля.

## Энергетический бюджет

Создание статического поля требует положительной энергии
`E_field`, вычисляемой из квадратов градиентов и экранированной моды.
Если она выше `initial_work_joules`, запуск отвергается.

Перенос и связывание изменяют учтённую энергию свободных манонов в
потенциале `sum(n*phi*cell_volume)`. При снижении этой энергии
разница поступает в тепловой резервуар; увеличение оплачивается
из резервуара либо явно ограниченной внешней работы.

В F3 выводятся `FIELD |phi|`, число манонов, прошедших через
грани за шаг, `FIELD E`, `HEAT`, `WORK`.
В `Simulation::tracked_energy()` доступен суммарный энергетический
учёт локальной модели: энергия связи/тепла плюс статическое поле,
потенциальная энергия манонов и тепловой остаток.
Внешняя работа отдельно учитывается в `operating_work_joules`.

Это **минимальная проверяемая бухгалтерия**, не полная общая модель
всех энергий (3.1), которая позднее должна включить материю,
упругие деформации, кинетическую энергию и динамику поля.

## Запуск и проверка причинности

```bash
cargo run --release --manifest-path apps/manonica-lab/Cargo.toml -- \
  apps/manonica-lab/experiments/potential_concentrator.toml
```

В F3 видны ненулевой потенциал и градиентный перенос. Для чистой
контрольной группы можно изменить только `mobility = 0.0`:
геометрия и начальные облака будут такими же, но не будет градиентного
переноса. Это позволяет отделить результат физического закона от
изменения визуального круга. Тесты сравнивают поле двух прогонов,
проверяют сохранение манонов и ограничение энергетического бюджета.

## Локальные условия на математических конструкциях

`[[local_boundaries]]` связывает **неподвижную математическую
траекторию** с численным условием для потенциала. Она не является
отдельным нарисованным эффектом: те же растеризованные ячейки
используются решателем, физическими ловушками и рендерером.

```toml
[[local_boundaries]]
formula = 0
kind = "dirichlet"
value = -4.0
```

Три поддерживаемых закона:

- **Дирихле:** `phi_i = value` — потенциал ячеек проводящего
  контура зафиксирован. Внешнее поддержание потенциала требует
  энергетического бюджета.
- **Нейман:** `∂phi/∂normal = 0` — численный обмен потенциалом
  через интерфейс между отмеченной и соседней ячейкой отсутствует.
  Также запрещён **градиентный** перенос манонов через этот интерфейс;
  диффузия свободных манонов остаётся отдельным законом.
- **Робин:** `-epsilon ∂phi/∂normal = h*(phi-reference)` —
  конечная связь с внешним резервуаром. В ячейковой дискретизации
  дополнительный коэффициент `exchange/dx` входит в диагональ
  системы. Например:

```toml
[[local_boundaries]]
formula = 0
kind = "robin"
reference = 0.0
exchange = 0.5
```

Для Неймана используется `kind = "neumann"`, без других параметров.

Эти условия применяются **на растеризованных ячейках**, а не точно
на непрерывной границе треугольной поверхности. Поэтому локальное
обусловливание сеточное и зависит от пространственного разрешения.
При пересечении двух независимо заданных локальных условий
эксперимент отвергается, а не выбирает условие по порядку записи.

Проверка законов выполняется в `crates/manonica-physics/tests/law_validation.rs`:
точный трёхъячеечный профиль Дирихле, отсутствие нормального
переноса через Нейман и одноклеточное аналитическое решение Робина.
Отдельный интеграционный тест проверяет, что геометрия формулы
действительно меняет рассчитанный потенциал.

Пример:

```bash
cargo run --release --manifest-path apps/manonica-lab/Cargo.toml -- \
  apps/manonica-lab/experiments/local_boundary_conductor.toml
```

Сценарий можно сравнить с `potential_concentrator.toml`. Визуальный
контур совпадает, но физическое поле, перемещение манонов и
энергетическая динамика будут различаться.

## Что ещё не входит в этап A

- Динамическое/волновое уравнение поля и возбуждения во времени.
- Точное наложение условий Дирихле/Неймана/Робина на непрерывных
  гранях конструкции; пока используется растеризованное приближение.
- Самосогласованное возбуждение поля связанными манонами или материей.
- Механический импульс и сила на обычные блоки (раздел 5).
- Необратимая энтропийная модель и полноценная тепловая диффузия
  в окружающей немагической среде.
- Визуализация 3D-градиентов отдельными стрелками и GPU ray marching.

Никакой из этих эффектов не симулируется скрытой командой заклинания.
