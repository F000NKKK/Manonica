# Manonica

**Manonica** — проект математической магической инженерии. Магия — следствие законов взаимодействия манонов, пространственных полей, материи и энергии, а не каталог заранее заданных заклинаний.

**Minecraft 26.3 / Fabric — только первая поддерживаемая комбинация.** Математические библиотеки не зависят от Minecraft или загрузчика.

## Устройство workspace

| Модуль | Ответственность |
| --- | --- |
| `manonica-error` | Единая типизированная классификация ошибок |
| `manonica-core` | Величины и единицы измерения, время, векторы, матрицы и общие трейты |
| `manonica-physics` | Фундаментальные свободные маноны, их движение и 3D-поле |
| `manonica-control` | Модульные П/И/Д, сигналы, пространство состояний и анализ |
| `manonica-simulator` | Изолированные воспроизводимые эксперименты |
| `adapters/minecraft/fabric/mc26_3` | Первое подключение к Minecraft |

**Кристаллы не являются частью `physics`.** Это будущая задача `materials`: кристаллическая решётка создаёт ловушки связанных манонов, а фундаментальное ядро не знает о конкретных минералах.

## Начало работы

Требуется стабильный Rust:

```bash
cargo fmt --all -- --check
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo run -p manonica-simulator
```

Для Minecraft-адаптера отдельно требуются Java 25 и Gradle 9.6:

```bash
cd adapters/minecraft/fabric/mc26_3
gradle build
```

Gradle Wrapper пока не добавлен. Java-адаптер сейчас только загружается в Minecraft; мост к Rust ещё предстоит создать.

## Архитектурные правила

1. `error` и `core` не знают ни о Minecraft, ни о манонах.
2. `physics` не знает о кристаллах, биологии, рунах и блоках Minecraft.
3. Микромодель манонов используется для экспериментов, макромодель — для масштабирования.
4. Параметры физических моделей подбираются по результатам проверки инвариантов.
5. Безопасность и сохранение энергии проверяются прежде, чем эффект применяется к миру.

См. [архитектуру](docs/ARCHITECTURE.md) и [этапы](docs/ROADMAP.md).

## Графическая лаборатория

В `apps/manonica-lab` реализованы декларативные эксперименты с полем
свободных манонов и рендерингом на Meridian SDK (WGPU). Для запуска:

```bash
cd apps/manonica-lab
cargo run --release
cargo run --release -- experiments/two_sources.toml
```

Схема TOML, библиотека `ExperimentBuilder`, визуализация геометрии
кругов, управление камерой и независимый численный решатель описаны
в [документации лаборатории](apps/manonica-lab/README.md).
Графическое приложение изолировано в отдельной Cargo workspace:
базовая физика не зависит от WGPU и Meridian Engine.
