# Игровая 3D-демка — промежуточная версия

## Запуск

```bash
cargo run --release --manifest-path apps/manonica-lab/Cargo.toml --bin manonica-game
```

`default-run = "manonica-lab"` сохраняет прежнюю команду запуска Lab.
Игровое окно использует тот же Meridian/WGPU, FIFO VSync и отдельный
поток рендера. Мир: 16 колонок 16×400×16, процедурный рельеф, арка,
ступени и кристаллы. Граница созданной области непроходима.

| Управление | Действие |
| --- | --- |
| WASD, мышь | Ходьба и обзор |
| Shift, Space | Бег, прыжок |
| ЛКМ | Собрать блок в инвентарь |
| ПКМ | Поставить блок / применить выбранный свиток |
| 1–6 | Камень, кристалл, трава, три свитка |
| Esc | Пауза и освобождение/захват курсора |
| R | Вернуться на точку появления |
| K / L | Сохранить / загрузить `saves/game.nbt` |

Коллизии персонажа, гравитация, прицел и взаимодействия реализованы в
`manonica-world`; рендер не владеет игровыми правилами. Снимок схемы v2
включает активные воздействия и свободные тела блоков. Файл сохраняется
через временный файл и переименование. Снимки v1 не мигрируются.

## Что зафиксировано в этом коммите

Свитки сейчас являются **сценарным прототипом**, а не завершённой
реализацией языка заклинаний. JSONL задаёт параметры трёх встроенных
типов. Временная логика планирует отделение вокселей и назначает начальные
импульсы. Далее тела движутся через `MechanicalBody` и общий учёт внешней
работы, с гравитацией и контактами. Тип блока, свойства и NBT сохраняются
в свободном теле; блоки не удаляются из учёта вещества.

Маноны резервируются из окружающей плотности и возвращаются после
окончания воздействия; проверяется сумма свободного и резервированного
запаса. Это **не** проверка полного энергобаланса заклинания. Временный
сценарный путь должен быть заменён, а не выдан за выведенный закон.

Рендер показывает объёмные частицы из WGSL: GPU рассчитывает ключевые
кадры траекторий при запуске, после чего кадры отображаются настоящими
3D-многогранниками без billboard-плоскостей. Показаны свободные тела
блоков, частицы среды, тряска камеры и пространственные линии каста.
Текущий круг общий и декоративный; он пока не отражает исполняемую
маноновую формулу. Поле плотности большого мира в этой демке ещё не
вычисляется чанковым GPU-backend.

## Согласованное направление следующего этапа

- JSONL должен содержать всю программу заклинания на языке формул,
  а не имя встроенной операции `explosion`/`rift`/`tornado`.
- Программа действует только на маноны и физические управляющие
  величины: концентрацию, удержание, давление, температуру, силу,
  пространственные и временные зависимости. В ней нет команд
  удаления блока или назначения импульса игровому объекту.
- Взрыв: сжатие, накопление энергии и резкое снятие удержания.
  Реальные силы, нагрев и разрушение определяет физический движок.
- Вихрь: поле сил увлекает вещество, закручивает и выбрасывает его.
  Смена состояния или разрушение допускаются только по общим законам
  материала; имя свитка не даёт разрешения уничтожать блоки.
- Рендер получает физические снимки: частицы показывают маноны/вещество,
  а контуры каста выводятся из исполняемой конструкции, а не из
  одинаковой геометрической заготовки.
- Связь манонового поля с разрушением обычного вещества ещё требует
  общего закона, коэффициентов материалов и эталонов энергии/импульса.
  Концентрационный и спектральный стенды пока являются разными моделями;
  их нельзя объявлять связанными только на основании красивого эффекта.

## Проверки контрольной точки

- 14 тестов `manonica-world`: движение и контакты, точный voxel-raycast,
  транзакционность неудачного каста, постепенное отделение и движение
  блоков, сохранение вещества и манонов, NBT-восстановление.
- Clippy с `-D warnings` для world и всех targets Lab; release-сборка игры.
- Оконный тест на RTX 4050/Vulkan: 600 кадров, три применённых свитка,
  объёмный WGSL-путь без ошибки GPU validation. Это функциональная
  проверка, не воспроизводимый benchmark производительности.

Автоматический оконный тест:

```bash
cargo run --release --manifest-path apps/manonica-lab/Cargo.toml \
  --bin manonica-game -- --showcase --smoke-frames 600
```
